# Warehouse

Консольний застосунок мовою **C++** для керування товарами на складі.

Проєкт дозволяє додавати, редагувати, шукати та сортувати товари, а також працювати з категоріями та зберігати дані у файлі.

## Можливості

- Додавання товарів
- Видалення товарів
- Редагування інформації про товар
- Перегляд списку товарів
- Створення та перегляд категорій
- Пошук товарів за різними параметрами
- Сортування товарів
- Збереження та завантаження даних із файлу

---

## Структура товару

Кожен товар містить:

| Поле | Опис |
|---|---|
| ID | Унікальний ідентифікатор |
| Назва | Назва товару |
| Виробник | Виробник товару |
| Категорія | Категорія, до якої належить товар |
| Ціна | Ціна товару |
| Кількість | Кількість на складі |
| Дата надходження | Коли товар надійшов на склад |
| Термін придатності | До якої дати товар придатний |

## Пошук

Пошук товарів виконується за:

- назвою
- виробником
- ціною
- категорією
- датою надходження
- терміном придатності

## Сортування

Доступне сортування за:

- ціною
- категорією

## Структура проєкту

Проєкт розділений на кілька файлів, щоб код було легше читати та підтримувати:

```text
main.cpp        # запуск програми та головне меню
warehouse.h     # структури даних, переліки, оголошення функцій
warehouse.cpp   # основна логіка програми
```
